# Система управления пользователями

## Обзор

VMS Dashboard включает полноценную систему управления пользователями с ролевой моделью доступа и детализированными разрешениями. Система основана на архитектуре OpenIPC Dashboard и адаптирована для React/TypeScript с темной стилистикой.

## Функциональность

### Роли пользователей

1. **Администратор (Admin)**
   - Полный доступ ко всем функциям системы
   - Управление пользователями
   - Настройка системы
   - Все разрешения по умолчанию

2. **Оператор (Operator)**
   - Ограниченный доступ с настраиваемыми разрешениями
   - Базовый доступ к просмотру камер
   - Детализированная система разрешений

### Разрешения для операторов

- **view_archive** - Просмотр архива записей
- **export_archive** - Экспорт видео из архива  
- **edit_cameras** - Управление камерами (добавление, редактирование)
- **delete_cameras** - Удаление камер
- **access_settings** - Доступ к настройкам системы
- **manage_layout** - Управление раскладками видео

## Интерфейс

### Главное окно управления пользователями
- **Список пользователей**: Отображение всех пользователей с их ролями
- **Кнопки действий**: Управление разрешениями, смена пароля, удаление
- **Добавление пользователя**: Кнопка для создания новых учетных записей

### Модальные окна

1. **Добавление пользователя**
   - Имя пользователя (обязательно)
   - Пароль (обязательно)
   - Роль (Администратор/Оператор)

2. **Смена пароля**
   - Поле для нового пароля
   - Подтверждение изменений

3. **Управление разрешениями** (только для операторов)
   - Список всех доступных разрешений
   - Чекбоксы для включения/отключения
   - Сетка в две колонки для удобства

## Стилистика

### Дизайн
- **Темная тема**: Соответствует общей стилистике приложения
- **Градиентные кнопки**: 
  - Зеленый для основных действий (Сохранить)
  - Серый для вторичных действий (Отмена, Разрешения)
  - Красный для опасных действий (Удалить)
- **Анимации**: Плавные переходы и hover-эффекты
- **Responsive**: Адаптивная сетка для разрешений

### CSS классы
```css
.modal-button.primary    /* Основные действия */
.modal-button.secondary  /* Вторичные действия */
.modal-button.danger     /* Опасные действия */
```

## Интеграция с бэкендом

### API методы (через Tauri)
```javascript
// Получение списка пользователей
await window.api.getUsers()

// Добавление пользователя  
await window.api.addUser({ username, password, role })

// Удаление пользователя
await window.api.deleteUser({ username })

// Смена пароля
await window.api.updateUserPassword({ username, password })

// Обновление разрешений
await window.api.updateUserPermissions({ username, permissions })
```

### Структура данных
```typescript
interface User {
  username: string;
  role: 'admin' | 'operator';
  permissions?: Record<string, boolean>;
}
```

## Безопасность

### Защита от ошибок
- **Валидация**: Проверка обязательных полей
- **Подтверждения**: Для опасных действий (удаление пользователей)
- **Последний администратор**: Защита от удаления последнего админа
- **Автокомплит**: Отключен для полей паролей

### Хеширование паролей
- Использование PBKDF2 с солью (в бэкенде)
- Безопасное хранение в keytar (Electron)
- Автологин с сохраненными учетными данными

## Использование

1. **Открытие**: Нажать кнопку управления пользователями в боковой панели
2. **Добавление**: Кнопка "Добавить пользователя" → заполнить форму → сохранить
3. **Разрешения**: Для операторов → кнопка "Права" → настроить чекбоксы → сохранить  
4. **Пароль**: Кнопка "Сменить пароль" → ввести новый → сохранить
5. **Удаление**: Кнопка "Удалить" → подтвердить действие

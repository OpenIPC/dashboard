# VMS Dashboard

A native Video Management System (VMS) desktop application for surveillance cameras, built with Tauri and React.

## Features

- Dashboard overview with key metrics
- Camera management with two connection methods:
  - MediaMTX integration for advanced stream processing
  - Direct RTSP connection for simple setup
- ONVIF camera discovery and auto-configuration
- Recordings playback
- Analytics with charts for alerts and recordings
- Native desktop application (no browser required)

## Getting Started

1. Install dependencies: `npm install`
2. Start the native application: `npm run tauri`
3. For web development (optional): `npm run dev`

## Build

To build the native application: `npm run tauri-build`

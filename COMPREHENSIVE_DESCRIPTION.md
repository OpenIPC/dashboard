# VMS Dashboard - Профессиональная система видеонаблюдения

## 🚀 Обзор
VMS Dashboard - это современная нативная desktop-система управления видеонаблюдением, разработанная на Tauri (Rust + React). Приложение обеспечивает полнофункциональное управление IP-камерами с поддержкой различных протоколов и производителей.

---

## 🎯 Ключевые возможности

### 📹 Управление камерами
- **Автоматическое обнаружение ONVIF-камер** в локальной сети
- **Поддержка множества протоколов**: ONVIF, RTSP, OpenIPC, Hikvision, Dahua
- **Два режима подключения**:
  - Прямое RTSP подключение для быстрого доступа
  - MediaMTX интеграция для расширенной обработки потоков
- **Автоматическая генерация RTSP URL** для различных брендов камер
- **Группировка камер** для удобного управления
- **Шифрование паролей** для безопасности

### 🖥️ Мультисеточная панель наблюдения
- **Гибкие макеты сетки**: от 1 до 64 камер одновременно
- **Настраиваемые шаблоны макетов** с сохранением конфигураций
- **Система вкладок** для быстрого переключения между макетами
- **Полноэкранный режим** для детального просмотра
- **Drag & Drop интерфейс** для перемещения камер между ячейками
- **Индивидуальные настройки** для каждой ячейки (звук, пауза, запись)

### 📊 Система архива и записи
- **Автоматическая запись** по расписанию или событиям
- **Интерактивная временная шкала** для навигации по архиву
- **Экспорт видеофрагментов** в различных форматах
- **Календарный интерфейс** для поиска записей по датам
- **Предварительный просмотр** миниатюр на временной шкале
- **Синхронизация воспроизведения** нескольких камер

### 📈 Аналитика и мониторинг
- **Статистика просмотров** и записей
- **Графики активности** камер по времени
- **Мониторинг состояния** всех подключенных устройств
- **Журнал событий** с фильтрацией и поиском
- **Алерты и уведомления** о проблемах с камерами

### 🔧 Расширенные функции
- **Встроенный медиа-сервер** MediaMTX для обработки потоков
- **HLS/WebRTC поддержка** для оптимизации трафика
- **Веб-интерфейс камер** прямо в приложении
- **RTSP аутентификация** с тестированием подключения
- **PTZ управление** (для поддерживаемых камер)
- **Система пользователей** с разными уровнями доступа

## 🏗️ Архитектура и технологии

### Frontend (React + TypeScript)
- **Material-UI** для современного интерфейса
- **HLS.js/Video.js** для воспроизведения видео
- **React Router** для навигации
- **Context API** для управления состоянием
- **Локализация** (русский/английский языки)

### Backend (Rust)
- **Tauri** для нативной производительности
- **Tokio** для асинхронной обработки
- **Reqwest** для HTTP/RTSP клиента
- **ONVIF протокол** поддержка
- **MediaMTX** интеграция для streaming
- **SQLite** для хранения конфигураций

### Безопасность
- **Шифрование паролей** AES-256
- **Изолированная среда** Tauri
- **Локальное хранение** данных
- **HTTPS/WSS** поддержка

## 🔌 Поддерживаемые протоколы и форматы

### Видео протоколы
- **RTSP/RTP** - основной протокол IP-камер
- **ONVIF** - стандарт для IP-видеонаблюдения
- **HLS** - HTTP Live Streaming для веб
- **WebRTC** - низкая задержка streaming

### Видео кодеки
- **H.264** - стандартный кодек
- **H.265/HEVC** - высокое сжатие
- **MJPEG** - для совместимости

### Производители камер
- **Hikvision** - полная поддержка API
- **Dahua** - ONVIF и прямое подключение
- **Axis** - ONVIF стандарт
- **OpenIPC** - открытая прошивка
- **Uniview, Tiandy, и другие** через ONVIF

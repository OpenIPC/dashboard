# Ускорение GPU через DirectML

## Обзор

VMS Dashboard поддерживает аппаратное ускорение аналитики через **DirectML** (DirectX Machine Learning). Это значительно снижает нагрузку на процессор и улучшает производительность для задач видеоаналитики, таких как распознавание номерных знаков, детекция лиц и подсчет объектов.

## 🚀 Преимущества

- **Снижение нагрузки на CPU на 60-90%** во время работы аналитики
- **Ускорение обработки в 2-5 раз** по сравнению с режимом CPU
- **Меньший нагрев** и энергопотребление системы
- **Лучшая многопоточность** - обработка большего количества камер одновременно

## 📋 Требования

### Оборудование
- **Windows 10 версии 1903 или новее** (рекомендуется Windows 11)
- **Видеокарта с поддержкой DirectX 12**:
  - NVIDIA: GTX 900 серии или новее
  - AMD: Radeon RX 400 серии или новее
  - Intel: HD Graphics 600 серии или новее (Kaby Lake+)

### Программное обеспечение
- **Обновленные драйверы GPU**:
  - NVIDIA: Последние Game Ready или Studio драйверы
  - AMD: Последние Adrenalin драйверы
  - Intel: Последние графические драйверы с сайта Intel

## ⚙️ Настройка

### 1. Включение ускорения GPU

1. Откройте **Настройки** (значок ⚙️)
2. Перейдите на вкладку **Аналитика**
3. Найдите выпадающий список **"Провайдер аналитики (GPU/CPU)"**
4. Выберите один из вариантов:
   - **Авто** (рекомендуется) - Автоматически использует GPU, если доступен
   - **GPU (DirectML)** - Принудительно использует GPU
   - **Только ЦП** - Отключает ускорение GPU

### 2. Проверка работы GPU

После сохранения настроек и запуска модуля:

1. Откройте **Консоль разработчика** (F12)
2. Проверьте **Console** на наличие сообщений:
   ```
   ✓ DirectML GPU acceleration is ENABLED and available
   → Analytics will use GPU for significantly better performance
   ```

Если видите предупреждения о недоступности DirectML:
- Обновите драйверы видеокарты
- Убедитесь в наличии Windows 10 1903+ или Windows 11
- Проверьте поддержку DirectX 12 вашей видеокартой

## 📊 Сравнение производительности

### Пример: Детекция номеров (1920x1080, 30fps)

| Режим | Нагрузка CPU | Нагрузка GPU | Время обработки |
|-------|--------------|--------------|-----------------|
| Только CPU | 40-60% | 0% | ~80-120мс |
| Авто/DirectML | 10-20% | 30-50% | ~20-40мс |

### Рекомендации по количеству камер

- **1-2 камеры**: Режим CPU приемлем
- **3-5 камер**: Рекомендуется GPU
- **6+ камер**: GPU настоятельно рекомендуется

## 🔧 Устранение неполадок

### GPU не обнаружен

**Симптомы**: В консоли отображается "DirectML provider not available"

**Решения**:
1. Обновите драйверы GPU до последней версии
2. Запустите Windows Update для получения обновлений DirectX 12
3. Проверьте поддержку DX12: `dxdiag` → Экран → Уровни компонентов
4. Попробуйте принудительный режим: Установите провайдер на "GPU (DirectML)"

### Высокая температура GPU

**Симптомы**: Температура GPU превышает 80°C

**Решения**:
1. Улучшите вентиляцию корпуса
2. Уменьшите количество активных камер
3. Увеличьте `analytics_frame_skip` в настройках (анализировать меньше кадров)
4. Уменьшите `analytics_resize_width` (обрабатывать кадры меньшего размера)

### Нестабильность системы

**Симптомы**: Зависания или сбои во время работы аналитики

**Решения**:
1. Обновите драйверы GPU
2. Переключитесь на режим "Авто" вместо принудительного DirectML
3. Попробуйте режим "Только ЦП" для изоляции проблемы GPU
4. Проверьте Журнал событий Windows на наличие ошибок драйверов

## 🎯 Лучшие практики

1. **Начните с режима Авто** - Пусть система сама определит доступность GPU
2. **Мониторьте нагрузку CPU/GPU** - Используйте встроенный монитор ресурсов
3. **Регулярно обновляйте драйверы** - Новые драйверы улучшают стабильность
4. **Оптимизируйте обработку кадров**:
   - Установите `analytics_resize_width` на 640-800 для большинства камер
   - Используйте `analytics_frame_skip` = 3-5 для пропуска кадров
5. **Тестируйте сначала на одной камере** - Проверьте работу GPU перед масштабированием

## 🔍 Технические детали

### Архитектура DirectML

```
Видеокадр → Изменение размера → YOLO детекция (GPU) → Постобработка → Результаты
                                          ↓
                                  OCR распознавание (GPU)
                                          ↓
                                  Валидация формата (CPU)
```

### Модели, использующие GPU

При включенном DirectML:
- ✅ YOLO v8 детекция номерных знаков
- ✅ CRNN OCR распознавание
- ✅ YOLO v8 детекция лиц
- ✅ YOLO v8 детекция/подсчет объектов

### Тонкая настройка производительности

Продвинутые пользователи могут настроить параметры ANPR для оптимизации GPU:

1. **Большее расширение обрезки** (1.3-1.5) - GPU лучше обрабатывает большие изображения
2. **Меньший пропуск кадров** (1-3) - GPU может обрабатывать больше кадров
3. **Включить Python OCR** - GPU эффективно обрабатывает коррекцию перспективы

## 🆘 Поддержка

Если ускорение GPU не работает:

1. Соберите логи из Консоли разработчика (F12) → Console
2. Запустите `dxdiag` и сохраните результат
3. Проверьте модель GPU и версию драйвера
4. Сообщите о проблеме с указанием:
   - Версии Windows
   - Модели GPU
   - Версии драйвера
   - Логов консоли с ошибкой DirectML

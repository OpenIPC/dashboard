# Новая система управления группами камер

Функционал групп камер был перенесен из старого приложения [OpenIPC/dashboard](https://github.com/OpenIPC/dashboard) и адаптирован под текущую архитектуру.

## 🎯 Принципы работы (по образцу старого приложения)

### **Структура данных:**
- **Камеры** имеют поле `groupId?: number | null`
- **Группы** - отдельные сущности с `id`, `name`, `cameraIds[]`, `createdAt`
- Камеры без группы имеют `groupId: null` и отображаются в секции "Без группы"

### **Отображение:**
- Группы показываются как **сворачиваемые секции** с иконками ▼/▶
- Каждая группа содержит список камер
- Камеры без группы отображаются в отдельной секции "Без группы"
- Кнопки редактирования/удаления групп находятся справа от названия

### **Функциональность:**

1. **📁 Создание группы:**
   - Кнопка "Создать папку" (📁) в панели инструментов
   - Простой диалог с полем ввода названия
   - Группа создается пустой

2. **🎯 Добавление камер в группу:**
   - **Drag & Drop**: перетаскивание камер между группами
   - Перетаскивание камеры на заголовок группы меняет её принадлежность
   - Перетаскивание в секцию "Без группы" убирает из всех групп

3. **✏️ Управление группами:**
   - **Редактирование**: кнопка ✏️ рядом с названием группы
   - **Удаление**: кнопка 🗑️ с подтверждением
   - При удалении группы все камеры перемещаются в "Без группы"

4. **👀 Визуальные элементы:**
   - Сворачиваемые секции групп (по умолчанию развернуты)
   - Выделение при перетаскивании
   - Иконки состояния групп (развернуто/свернуто)

## 🔧 Техническая реализация

### **Frontend (React/TypeScript):**
- **DevicePanel.tsx** - главный компонент с логикой групп
- **Camera interface** дополнен полем `groupId?: number | null`
- **CameraGroup interface** для описания групп
- **Drag & Drop API** для перемещения между группами

### **Стили (Material-UI):**
- Темная тема (`#2a2f33`, `#3b4146`) в соответствии с общим дизайном
- Адаптивные hover-эффекты
- Плавные анимации сворачивания/разворачивания (Collapse)

### **Backend (Rust/Tauri):**
В перспективе нужно добавить:
- `get_groups()` - получение списка групп
- `save_groups(groups)` - сохранение групп
- `get_cameras()` и `save_cameras()` - уже существуют, нужно учесть `groupId`

## 📱 Как использовать

1. **Создать группу**: Нажмите кнопку 📁 в панели инструментов → введите название
2. **Добавить камеру в группу**: Перетащите камеру на заголовок нужной группы
3. **Убрать из группы**: Перетащите камеру в секцию "Без группы"
4. **Редактировать группу**: Нажмите ✏️ рядом с названием группы
5. **Удалить группу**: Нажмите 🗑️ рядом с названием (с подтверждением)

## 🔄 Автосохранение

Все изменения групп автоматически сохраняются:
- При создании/удалении группы
- При перемещении камер между группами  
- При переименовании групп

Данные сохраняются через Tauri API в файловую систему.

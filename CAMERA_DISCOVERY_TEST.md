# Тестирование функционала поиска камер

## 🔍 Как проверить работу поиска камер:

### **1. Запуск поиска:**
- Нажмите кнопку 🔍 "Поиск камер" в панели инструментов DevicePanel
- Откроется диалог "Найденные камеры"
- Поиск запустится автоматически

### **2. Что происходит под капотом:**
- **Frontend** вызывает `invoke('discover_cameras')`
- **Rust backend** запускает высокопараллельный TCP-сканер по каждому сетевому интерфейсу:
  - Пул из 96 асинхронных задач проверяет подсети `/24`
  - Cканируются типовые порты видеокамер: 554, 8554, 7447, 80, 8000, 8080, 8899, 2020
  - На успешной TCP-сессии дополнительно пробуем опросить HTTP-заголовки для определения модели
- Найденные устройства отправляются через события `device-found`
- Прогресс сканирования передаётся событиями `device-discovery-progress`
- Завершение (или ошибка) помечается событием `device-discovery-finished`
- **Frontend** прослушивает события и обновляет диалог "Найденные камеры"

### **3. Логи для отладки:**
В консоли DevTools должны появиться сообщения:
```
Starting camera discovery...
[VMS] discover_cameras: start
[VMS] discover_cameras: scanning 254 addresses
Received device-found event: {ip: "192.168.1.100", name: "ONVIF Camera", protocol: "onvif", detectedPort: 554}
[VMS] discover_cameras: scan completed
```

В консоли Rust (терминал):
```
[VMS] discover_cameras: scanning 254 addresses
[VMS] Found camera candidate 192.168.1.100 on port 554
[VMS] discover_cameras: scan completed (found 3)
```

### **4. Возможные проблемы:**

**Проблема:** Список камер пустой
- **Причина:** Нет ONVIF камер в сети или они недоступны
- **Решение:** Проверить сеть, убедиться что камеры поддерживают ONVIF

**Проблема:** События не приходят
- **Причина:** Не работает подписка на события
- **Решение:** Проверить `listen('device-found')` в DevicePanel

**Проблема:** Сканирование зависает
- **Причина:** Таймауты сети слишком большие
- **Решение:** Уменьшить таймауты в discovery.rs (сейчас 200ms)

### **5. Тестирование в локальной сети:**
- Убедитесь, что камеры включены и подключены к той же сети
- Проверьте настройки файрвола (могут блокировать UDP/TCP сканирование)
- Попробуйте найти камеры вручную по IP

### **6. Симуляция для тестирования:**
Можно добавить тестовые данные, временно изменив `discoverCameras`:
```typescript
const discoverCameras = async () => {
  // Симуляция найденных камер для тестирования
  setFoundCameras([
    { name: "Test Camera 1", ip: "192.168.1.100", protocol: "onvif" },
    { name: "Test Camera 2", ip: "192.168.1.101", protocol: "onvif" }
  ]);
};
```
